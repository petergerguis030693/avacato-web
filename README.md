# مكتب الأفوكاتو (Avacato) — Website

Egyptian law firm website · Arabic RTL · Next.js static export.

- **Live:** https://avacato.smarttech-connection.com
- **Stack:** Next.js App Router, `output: 'export'`, Tailwind, Cairo font
- **Brand:** Navy `#0B1C2C` + Gold `#C9A227`

## Develop

```bash
npm install
npm run dev
npm run build   # writes to out/
```

## Soft-deploy

Static files → `/var/www/avacato/` on `81.173.84.89`
